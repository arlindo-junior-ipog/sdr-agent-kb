# Curso de Extensão Universitária: Microsoft Power BI — Análise de Dados Corporativos e Criação de Dashboards Gerenciais

## Resumo para qualificação (SPIN)
Indicado para o lead que menciona: quer aprender Power BI, DAX, criação de
dashboards gerenciais, ou automação de relatórios. Bom fit para qualquer
profissional que trabalha com dados e apresentação de resultados, independente da
área. **Atenção:** existem múltiplas versões/cargas horárias deste curso nos
materiais de origem — ver "Alertas".

## Ficha técnica
- **Tipo:** Curso de Extensão Universitária
- **Carga horária:** 32 horas
- **Modalidade:** On-line e Ao Vivo (via Zoom)
- **Estrutura:** 8 módulos
- **Horários:** "Confirme com seu consultor as datas e horários das aulas"
- **Atividades práticas:** modelo de Sala de Aula Invertida no ambiente virtual

## Para quem é o curso
Todos os profissionais que desejam utilizar o Power BI nas atividades diárias,
ganhando tempo e produtividade e se destacando no mercado de trabalho. Requisito:
computador com Windows (a partir do Windows 8, recomendado 8GB RAM e SSD); noções
básicas de Excel ajudam, mas não são obrigatórias.

## Documentação necessária para matrícula
Não especificada explicitamente no material de origem.

## Módulos (ementa resumida)
1. Tópicos Iniciais (introdução ao BI, instalação do Power BI Desktop)
2. Integrações e Conectividade de Dados com Power BI (Excel, CSV, TXT, SQL)
3. Relacionamentos (tabelas fato/dimensão, cardinalidades)
4. Principais Funções DAX
5. Criando Temas de Apresentação e Layouts
6. Utilização dos Conhecimentos Adquiridos para Criação do Dashboard Final
7. Power BI Mobile e Web
8. Atualização e Integração Automática de Dados (Gateway)

- Uso de recursos de IA no Power BI para análise automática de dados e explicação de
  variações nos resultados.

  em cursos curtos de Power BI.

  conteúdo do curso.

  aplicação prática de negócio, não apenas técnica de ferramenta.
