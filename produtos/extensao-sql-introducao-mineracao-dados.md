# Curso de Extensão Universitária: SQL com Introdução à Mineração de Dados

## Resumo para qualificação (SPIN)
Indicado para o lead que menciona: aprender SQL, modelagem de banco de dados, ou
mineração de dados/data warehouse. Bom fit para qualquer profissional que precisa
lidar com dados no trabalho, mesmo sem background técnico prévio.

## Ficha técnica
- **Tipo:** Curso de Extensão Universitária
- **Carga horária:** 20 horas
- **Modalidade:** On-line e Ao Vivo (via Zoom)
- **Estrutura:** 4 módulos
- **Horários:** "Confirme com seu consultor as datas e horários das aulas"
- **Atividades práticas:** modelo de Sala de Aula Invertida no ambiente virtual

## Para quem é o curso
Pessoas de qualquer área de atuação, preferencialmente com noções de dados ou bancos
de dados, que precisem transformar dados em informações ou lidar com mineração de
dados.

## Documentação necessária para matrícula
Não especificada explicitamente no material de origem.

## Módulos (ementa resumida)
1. Fundamentos de banco de dados, modelo Entidade-Relacionamento, normalização e
   noções de Mineração de Dados
2. Linguagem SQL DDL (CREATE TABLE, ALTER TABLE, DROP TABLE, CREATE INDEX,
   CONSTRAINT)
3. Linguagem SQL DML (INSERT, DELETE, UPDATE, SELECT, JOINs, subconsultas)
4. Construção de um armazém de dados (data warehouse) e aplicação de algoritmos de
   classificação, predição e agrupamento

## Diferenciais para argumentação
- Cobre tanto a base técnica de SQL (DDL/DML, praticamente todos os SGBDs do
  mercado usam esse padrão) quanto uma introdução aplicada a mineração de dados —
  raro em cursos curtos de SQL, que costumam parar na consulta básica.
- Professor com experiência real como Analista de Sistemas de longa data (Tribunal
  de Justiça de Goiás) e docência universitária em Ciência da Computação.
- Formato curto (20h) e acessível para quem não vem de TI.

## Objeções comuns específicas deste curso
- "Preciso ter experiência em programação para fazer esse curso?" → Não; é indicado
  para qualquer área, preferencialmente com alguma noção prévia de dados ou bancos de
  dados, mas não exige experiência em programação.
