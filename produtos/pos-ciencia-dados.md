# Ciência de Dados

## Ficha técnica
- **Tipo:** Pós-Graduação
- **Carga horária:** 432 horas
- **Modalidade:** On-line e Ao Vivo
- **Formato (conforme o material):** 1 final de semana por mês; 12 módulos; Sexta 18h às 23h; Sábado 08h às 19h; Domingo 08h às 13h; Aulas On-line e Ao Vivo via plataforma Zoom
- **Atividades práticas:** As atividades práticas acontecem utilizando o modelo de Sala de Aula Invertida. Trata-se do estudo do conteúdo organizado pelo professor, com a realização de atividades de ancoragem e preparatórias que envolvem cases temáticos e aplicação de ferramentas, potencializando a aprendizagem e retenção do conteúdo durante as aulas ao vivo.

## Sobre o curso
A matéria-prima da Pós em Ciência de Dados do IPOG é um mix equilibrado de visão de negócios, visão de projetos, teoria, ferramentas, programação e cenários do mundo real. O curso é voltado para a prática da profissão, com o suporte de professores atuantes no mercado. Um diferencial importante é o módulo estrategicamente posicionado ao meio do curso, que permite aferir a aprendizagem efetiva do aluno. Dessa forma, o aluno, de forma autônoma, pode se autoavaliar quanto ao aproveitamento dos conteúdos dos módulos anteriores e revisar, quando necessário, as temáticas que ainda não foram suficientemente praticadas. Reunidos em um único curso, oferecemos o conhecimento necessário para o início de uma carreira sólida em Ciência de Dados, respeitando o ritmo de aprendizagem de cada aluno e permitindo que profissionais de outras áreas das TICs ingressem nesse campo do conhecimento.

## Para quem é o curso
- Analistas de Sistemas, Desenvolvedores, programadores, outros profissionais das TICs que desejem migrar de sua área para atuar com Ciência de Dados, assim como ampliar as possibilidades na sua carreira, e que gostem de resolver problemas de forma estruturada.

## O que você vai fazer no curso
- Desenvolver competências em linguagem de programação, técnicas, algoritmos e ferramentas necessários à aplicação da Ciência de Dados orientados ao mercado;
- Adquirir conhecimentos diferenciadores e práticos para possibilitar o alinhamento adequado entre o profissional de Ciência de Dados e o team de business, C-levels, CEO;
- Conhecer os algoritmos essenciais de Machine Learning para resolver problemas complexos de dados em negócios, criando oportunidades e desenvolvendo as competências necessárias para extrair insights valiosos, suportando os tomadores de decisão nas organizações.

## Módulos (ementa resumida)
As ementas poderão ser ajustadas conforme demandas de mercado, novas legislações, novos cenários e contextos.

1. Introdução à Ciência de Dados
   - Desafios, oportunidades, tendências, linguagens e os paradigmas relacionados com a Ciência de Dados.
   - Mindset profissional.
   - Skills e o mercado.
   - Business Analytics.
2. Estatística aplicada à Ciência de Dados
   - Estatística e conceitos associados a situações do mundo real.
   - Técnicas para visualizar e resumir dados, como histogramas, gráficos de dispersão, tabelas de frequência e medidas de resumo descritivo.
   - Conceitos essenciais apresentados com foco em utilidade e oportunidade.
3. Python Essencial
   - Estruturação dos ambientes para trabalhar com Python, desde os primeiros passos até o desenvolvimento de soluções profissionais, passando por lógica, estrutura de dados, consultas a bancos de dados e conhecimentos básicos para pavimentar o acesso à análise de dados.
4. Python em Análise de Dados
   - Apresentação e experimentação dos recursos mais importantes em estruturas de dados, bibliotecas para coleta, manipulação, análise e exploração visual de dados.
5. Machine Learning – Nível 1
   - Conhecer e praticar os algoritmos principais, entender como os modelos treinam e como medir resultados de performance.
   - Explorar os fundamentos de modelos como Linear Regression, Decision Tree, Random Forest, K-Means e Hierarchical Clustering.
6. Bootcamp
   - Módulo para consolidar as competências em identificação de problemas, obtenção, preparação, limpeza, formatação e extração de insights dos dados. Sessões conduzidas pelo docente incluem um mix de demonstrações e verificações curtas de compreensão, nas quais o aluno, de forma independente, estrutura, viabiliza e apresenta a solução para um problema ou oportunidade de negócio com o suporte do conhecimento vivenciado em Ciência de Dados.
7. Machine Learning – Nível 2
   - Aprender conjunto de técnicas de Machine Learning usadas para encontrar padrões em dados não rotulados.
   - Entender como aplicar os algoritmos que descobrem estruturas interessantes nos dados.
   - Experimentar o processo de descobrir as relações entre os atributos de dados.
8. Deep Learning
   - Aspectos de redes neurais profundas para modelar dados complexos, como imagens, áudio e texto.
9. Times Series Forecasting
   - Desenvolver os conhecimentos necessários de séries temporais, análises e previsões de séries temporais.
   - Conhecer os componentes e técnicas para modelar séries temporais, modelos de suavização exponencial, redes neurais recorrentes e modelos LSTM.
10. Visualização de Dados e Data Storytelling
   - Aprender os fundamentos da comunicação eficiente de informações para usuários de negócios.
   - Aprender a reconhecer características dinâmicas para aprimorar as interfaces visuais de dados, melhorando a apresentação dos insights produzidos pela Ciência de Dados utilizando Power BI e Google Data Studio, comunicando em alto nível as percepções a partir das análises do ponto de vista não técnico.
11. Gestão de Projetos em Ciência de Dados
   - Problemas de negócios, requisitos de negócios, modelagem, produção, ciclo de vida de projetos de Ciência de Dados.
12. Projetos – Mentoria
   - Elaborar um projeto a partir de dados reais de algum modelo de negócio utilizando ferramentas, modelos e plataformas aplicadas, vivenciados neste curso.
